# 手机免广告助手

这是一个用于学习 Android 无障碍服务和界面自动化的个人项目。助手根据规则识别开屏广告的「跳过」按钮，以及部分首页促销弹窗的关闭按钮，并代为点击。项目仍在完善中。

## 规则覆盖

目前只适配了作者常用的部分应用，包括百度网盘、滴滴出行、铁路 12306、携程旅行、智行火车票、小米应用商店和中国移动。每个应用的规则覆盖范围不同，具体以 [拦截规则](outputs/拦截规则) 中的 JSON 文件为准。

通用规则会识别常见的「跳过」文字和满足匹配条件的促销弹窗。专属规则根据各应用实际提供的控件标识、结构和位置进行匹配。应用版本、设备和广告样式变化都可能影响效果。

## 使用和构建

- 安装 APK 后，在 Android 设置中开启助手的无障碍服务，并在助手首页勾选要处理的应用。首页「总开关」可随时暂停或恢复拦截。
- 在 Windows 上构建需要 JDK、Android SDK Platform 35 和 Android Build Tools。按 [构建脚本](work/build-adskipper.ps1) 所用目录准备依赖后，运行 `pwsh -File work/build-adskipper.ps1`，生成 `outputs/phone-adskipper.apk`。
- 电脑控制台用于调试。需要采集日志时，连接自己的测试设备，在 [采集脚本](work/capture-adskipper-logs.ps1) 中通过 `-Serial` 参数指定 ADB 设备。

## 使用风险

- **自动点击可能漏判或误判。** 应用更新、弹窗布局变化、控件加载延迟都可能让规则失效。进行支付、下单或填写重要信息时，可先暂停拦截。
- **无障碍权限可读取界面控件并执行点击。** 截图和调试日志可能包含屏幕内容、界面文字或应用使用记录。可在首页关闭「保存广告截图」，分享截图或日志前请先检查并脱敏。
- **ADB 调试会授予已授权电脑设备调试能力。** 请只连接自己有权调试的设备和可信电脑，调试结束后可关闭无线调试。
